# Tools Used

| # | Tool | Purpose |
| - | ---- | ------- |
| 1 | [CyberChef](https://gchq.github.io/CyberChef/) | Encode and decode data (for example, Base64) |
| 2 | [7-Zip](https://www.7-zip.org/) | Extract ZIP files |
| 3 | [Gary Kessler File Signatures](https://www.garykessler.net/library/file_sigs.html) | Match the magic number (file header) to find the true file type |
| 4 | [ExifTool](https://exiftool.org/) | Read file metadata (it can also scan all files in a folder) |
| 5 | Online file viewer (similar to [SquareX](https://sqrx.com/)) | Open and interact with files in a sandbox |
